# ActionButton12 APT Repository

Официальный APT-репозиторий для **ActionButton12** by **@cocxace**.

## 🚀 Как добавить репозиторий:

### В Sileo:
Нажмите на ссылку в Safari на вашем iPhone:
👉 **[Добавить в Sileo](https://cocxace.github.io/actionbutton12/)**

Или вручную в Sileo -> **Источники** -> **+**:
```text
https://cocxace.github.io/actionbutton12/
```

### Прямая установка .deb:
Файл .deb находится в папке `debs/`:
`debs/com.cocxace.actionbutton12_1.0.0_iphoneos-arm.deb`

## 📱 Описание твика ActionButton12:
- Имитация Action Button (iPhone 15 Pro) на iPhone 5s (iOS 12.0 - 12.5.8).
- Вызов через долгое нажатие Power (0.6 сек) и/или двойное нажатие Home.
- 4 настраиваемых быстрых действия (фонарик, камера, диктофон, скриншот, Wi-Fi, Bluetooth).
- Плавные ползунки громкости и яркости прямо в HUD.
- Твик с PreferenceBundle в Настройках iOS.
